# 后端导入与 API 使用

## 安装依赖

在 `backend` 目录安装依赖：

```bash
pip install -r requirements.txt
```

## 导入原始数据

从工作区根目录运行：

```bash
$env:PYTHONPATH=".\backend"
python -m app.importer --reset
```

导入器会：

- 跳过 `0现货数据整理` 下的加工表。
- 导入用电侧日前/实时 24 点价格。
- 导入发电侧关键 96 点曲线。
- 自动聚合 96 点为小时均值。
- 生成 SQLite 数据库：`data/guangxi_spot.db`。

当前已验证导入结果：

- 原始 Excel：3300 个。
- 小时价格：4104 条。
- 15 分钟曲线：131328 条。
- 小时聚合曲线：32832 条。
- 导入错误：0。

## 数据表

### spot_price_hourly

小时级价格表：

- `market_date`
- `market_type`：`day_ahead` 或 `real_time`
- `hour`
- `price_yuan_mwh`
- `volume_mwh`
- `source_file`

### power_curve_15min

15 分钟级供需曲线：

- `market_date`
- `data_type`
- `region`
- `time_point`
- `quarter_index`
- `value_mw`
- `source_file`

### power_curve_hourly

从 96 点聚合出的小时曲线：

- `market_date`
- `data_type`
- `region`
- `hour`
- `value_mw_avg`
- `source_15min_count`
- `source_file`

## 启动 API

```bash
$env:PYTHONPATH=".\backend"
uvicorn app.main:app --reload --port 8000
```

启动后打开：

`http://127.0.0.1:8000/`

页面包含：

- 交易日期选择。
- 重新导入原始数据按钮。
- 日前均价、实时均价、平均价差、最高/最低价格。
- 日前与实时价格曲线。
- 实时-日前价差柱状图。
- 近 14 日日前/实时均价趋势。
- 数据完整性评分和缺失项检查。
- 24 小时报价倾向和原因说明。
- 目标日报价辅助模式：当目标日没有实时价格时，仍可基于日前价格和预测披露数据生成建议报价区间。

## 第一版 API

### 健康检查

`GET /api/health`

### 日期列表

`GET /api/dates`

返回哪些日期有日前、实时、曲线数据。

### 重新导入原始数据

`POST /api/import`

会重新扫描 `现货交易电网信息` 目录，跳过加工表，清空并重建当前分析数据库。

### 价格曲线

`GET /api/prices/{market_date}`

例如：

`GET /api/prices/2026-05-24`

返回 24 小时日前价格、实时价格和价差。

### 供需曲线

`GET /api/curves/{market_date}`

返回该日小时聚合后的负荷、新能源、备用、发电出力等曲线。

### 价格摘要

`GET /api/summary/{market_date}`

返回均价、最高价、最低价、峰谷差、高价小时、低价小时、实时价差。

### 历史趋势

`GET /api/history/{market_date}?days=14`

返回指定日期之前含当日的日均价格趋势：

- 日前均价。
- 日前最高价。
- 日前最低价。
- 实时均价。
- 平均价差。

### 数据完整性

`GET /api/quality/{market_date}`

返回该日数据质量检查：

- 日前价格是否满 24 小时。
- 实时价格是否满 24 小时。
- 广西统调负荷、新能源、非市场化机组、正备用、负备用等小时聚合是否完整。
- 完整性评分。

### 策略建议报告

`GET /api/report/{market_date}`

返回：

- 当日结论。
- 价格摘要。
- 每小时报价倾向。
- 风险等级。
- 原因说明。
- 同小时历史分位。
- 近 7 日同小时均价。
- 较前一日同小时变化。
- 广西水电、新能源、统调负荷、省间联络线、非市场化机组、备用等供需指标。
- 目标日/复盘模式标识。
- 建议报价下限、建议中枢、建议上限。
- 供需松紧指数和松紧标签。
- 相似历史小时样本。

当前策略逻辑会综合：

- 日前价格绝对水平。
- 日前价格同小时历史分位。
- 日前价格相对近 7 日同小时均价的偏离。
- 日前价格相对前一日同小时的变化。
- 实时-日前价差。
- 新能源出力占负荷比例。
- 供给侧：水电 + 新能源。
- 需求侧：统调负荷 + 广西受西电计划。
- 正备用水平。
- 负荷扣除非市场化机组后的缺口。
- 相似历史小时的日前价、实时价和价差。

当目标日缺少实时价格时：

- `mode` 返回 `target_day`。
- 实时价格和实时价差为空。
- 系统仍基于日前价格、同小时历史分位、近 7 日同小时均值、供需松紧、历史实时偏差和相似历史小时生成建议报价区间。

相似历史小时匹配当前使用：

- 需求合计：统调负荷 + 广西受西电计划。
- 供给合计：水电 + 新能源。
- 正备用。
- 新能源出力。

系统会在目标日前约 45 个历史日期中按同小时匹配相似样本，并返回最相似的若干小时作为报价参考。
